Read the catalog

One file lists every collection and piece with its ETH and IMD prices, availability, contract and chain. It is built from the chain, so it never disagrees with it.

02

Buy with one call

Every piece is a one-of-one, so name it by id and check it is still available. Pay in ETH, or in IMD after approving it once. Send exactly the price; any other amount reverts, so nothing is lost to a rounding mistake. Pass a broker, or the zero address.

// viem: pay in ETH
await wallet.writeContract({
  address: artHouse,
  abi,
  functionName: 'mint',
  args: [1n, 42n, broker ?? zeroAddress],
  value: priceWei,
})

// or pay in IMD: approve once, then mint
await wallet.writeContract({
  address: imd,
  abi: erc20Abi,
  functionName: 'approve',
  args: [artHouse, priceIMD],
})
await wallet.writeContract({
  address: artHouse,
  abi,
  functionName: 'mintWithIMD',
  args: [1n, 42n, broker ?? zeroAddress],
})
03

Read the art from chain

tokenURI returns the full metadata with the SVG inside it. No gateway to trust. Check sealed to confirm the art can never change.

ArtCollection.tokenURI(id)
// → data:application/json;base64,…
//   { name, artist, image: "data:image/svg+xml;base64,…" }

ArtStorage.sealed(collection)   // → true
